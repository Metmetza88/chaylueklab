# WORAMET AI LAB — Business Insights MVP

เครื่องมือช่วยร้านค้าขนาดเล็กอ่านยอดขายจาก CSV ดูสินค้าขายดี และเตรียมข้อความโปรโมต โดยประมวลผลในเบราว์เซอร์ ไม่มีค่า API และไม่ต้องสมัครสมาชิก

**สถานะจริง:** ใช้สูตรและกฎพร้อมเทมเพลต ยังไม่ได้เชื่อมและทดสอบ Generative AI ทางเชื่อมฝั่งเซิร์ฟเวอร์ปิดไว้ ไม่ใช่ระบบบัญชีหรือระบบขายหน้าร้าน

ใช้ Repository เดิม `Metmetza88/chaylueklab` และสาขา `feature/woramet-dojo-mvp-20261113` เท่านั้น ติดตั้ง Node.js 24 LTS ฟรีก่อน แล้วเปิด Terminal ที่โฟลเดอร์ Repository:

```powershell

```

เปิด <http://127.0.0.1:4173/ai-money-studio/business-insights.html> ใน Chrome หรือ Edge แล้ว:

1. กด **ดูผลด้วยข้อมูลสมมติ** จะเห็นยอดขาย 7,200 บาท / 12 ชิ้น / 7 แถว / 3 สินค้า
2. หรือเลือกไฟล์ `ai-money-studio/fixtures/thai-sales-14-days.csv` แล้วกด **วิเคราะห์ยอดขาย** จะได้ 2,100 บาท และยอด 7 วันล่าสุดเพิ่ม 100% เมื่อเทียบ 7 วันก่อนหน้าในชุดสมมตินี้
3. ดูอันดับสินค้า ข้อสังเกต และร่างโพสต์จากเทมเพลต
4. ดาวน์โหลดรายงาน `.txt` หรือ `.json` และคัดลอกหรือบันทึกร่างโพสต์ `.txt`
5. กด **ล้างข้อมูล** เมื่อใช้งานเสร็จ กด Ctrl+C ใน Terminal เพื่อปิดเครื่องทดลอง

ไม่มี `npm install` สำหรับตัวแอปหรือชุดทดสอบหลัก และไม่มีการเปิดเซิร์ฟเวอร์สู่ภายนอก หากพอร์ตซ้ำ ใช้ PowerShell `$env:WORAMET_PORT="4174"` แล้วเริ่มใหม่

## CSV ที่รองรับ

```csv
date,product,quantity,unit_price
2026-11-01,สมุดตัวอย่าง,2,35.50
2026-11-02,"ปากกา, สีน้ำเงิน",1,"1,200.50"
```

- คอลัมน์จำเป็น: `product` / `สินค้า` / `ชื่อสินค้า`, `quantity` / `qty` / `จำนวน`, `unit_price` / `price` / `ราคาต่อหน่วย` / `ราคา` ตัวพิมพ์เล็กใหญ่ไม่ต่างกัน
- ตัวคั่น: comma, semicolon หรือ tab ตรวจจากหัวตาราง รองรับอัญประกาศคู่และ `""` ภายในชื่อ
- Encoding: UTF-8 รวม BOM, UTF-16 LE/BE ที่มี BOM หรือเลือก Windows-874 สำหรับไฟล์ภาษาไทยรุ่นเก่า ไม่เดา encoding รุ่นเก่าเงียบ ๆ
- จำนวนเป็นจำนวนเต็มบวกไม่เกิน 10,000,000 ต่อแถว ราคา 0–100,000,000 บาท มีทศนิยมไม่เกิน 2 หลัก รองรับเลขไทยและ comma หลักพันที่ถูกต้อง ไม่รองรับ decimal comma หรือเลขวิทยาศาสตร์
- วันที่ไม่บังคับ ใช้ `date` / `วันที่` รูปแบบ `YYYY-MM-DD`, `YYYY/MM/DD`, **วัน/เดือน/ปี** `DD/MM/YYYY` (ใช้ `-` `/` `.` ได้) หรือชื่อเดือน เช่น `1 พ.ย. 2569` / `15 Nov 2026` (ตัวเลขแบบวัน/เดือนเสมอ ไม่ตีความเป็นเดือน/วัน) เวลาท้ายวันที่แบบไม่มีเขตเวลาจะถูกละเว้น รูปแบบ ISO ที่มี `T`/`Z`/offset ถูกปฏิเสธ ราคาใส่ `฿`, `THB` หรือ `บาท` ได้ รองรับ พ.ศ. และ ค.ศ. ถ้ามีคอลัมน์วันที่ต้องถูกต้องทุกแถว
- สูงสุด 2 MB, 10,000 แถว, 64 คอลัมน์ ชื่อสินค้าไม่เกิน 160 ตัวอักษร ไม่ขึ้นบรรทัดใหม่ ไม่ใช้ตัวควบคุมที่ทำให้รายงานสับสน
- ถ้าพบข้อมูลผิดจะไม่แสดงยอดรวมบางส่วน แต่ให้แก้ก่อน คอลัมน์ว่าง/ซ้ำหรือความหมายซ้ำ เช่น `qty` กับ `quantity` จะถูกปฏิเสธ
- เงินคำนวณเป็นสตางค์จำนวนเต็ม หากเกินช่วงที่ JavaScript คำนวณได้แม่นยำจะให้แบ่งไฟล์

## อ่านผลอย่างไร

ยอดขาย = จำนวน × ราคาต่อหน่วย ผลรวมนี้ไม่ใช่กำไร ไม่หักต้นทุน ส่วนลด ค่าธรรมเนียม ภาษี หรือคืนสินค้า จำนวนแถวไม่ใช่จำนวนบิล รายการซ้ำจะถูกนับตามเดิม ชื่อสินค้าที่เหมือนกันจะถูกรวม แต่ไม่ได้รวมรหัส/คำสะกดที่ต่างกันให้อัตโนมัติ

อันดับหลักเรียงตามยอดขาย และมีข้อสังเกตแยกสินค้าที่ขายได้มากสุดตามจำนวน กรณียอดเท่ากันเรียงตามชื่อ ไม่มีข้ออ้างว่าโปรโมตแล้วจะขายดีขึ้น

แนวโน้มเปรียบเทียบ 7 วันล่าสุดกับ 7 วันก่อนหน้า **เฉพาะเมื่อมีรายการครบทุกวันในช่วง 14 วันล่าสุดของข้อมูล** วันที่หายไปไม่ถูกแทนเป็นศูนย์ ไม่มีวันที่ก็วิเคราะห์ยอดรวมได้แต่ไม่มีแนวโน้ม ไม่พยากรณ์อนาคต ถ้าฐานก่อนหน้าเป็นศูนย์จะไม่คิดเปอร์เซ็นต์

## ข้อมูลและความปลอดภัย

ตัวหน้า Insights ไม่เรียกเครือข่ายภายนอก ไม่มี analytics, localStorage, cookie หรือฐานข้อมูล CSP ปิด `connect-src` และผลจาก CSV แสดงเป็นข้อความเพื่อป้องกัน HTML ทำงาน ข้อมูลที่แก้ไข เลือกใหม่ อ่านไม่ได้ หรือล้างแล้ว จะยกเลิกรายงานเก่ารวมถึงงานอ่านไฟล์ที่ยังไม่เสร็จ

ใช้ไฟล์สมมติหรือไฟล์ที่ลบข้อมูลส่วนตัวแล้ว คอลัมน์อื่นไม่ถูกนำไปรายงาน แต่ยังอยู่ในช่องข้อความระหว่างเปิดหน้า ไฟล์ TXT/JSON ที่ดาวน์โหลดมีชื่อสินค้าและยอดขาย อย่าแชร์โดยไม่ตรวจสอบ ไม่มีการเผยแพร่โพสต์หรือส่งข้อความให้อัตโนมัติ

## รันทดสอบ

จากราก Repository:

```powershell
node --test ai-money-studio/tests/*.test.cjs ai-money-studio/tests/*.test.mjs
node --test tests/*.test.mjs
node scripts/verify-public-site.mjs
```

ชุดแรกทดสอบการคำนวณ CSV หน้าจอจำลอง การอ่านไฟล์ซ้อน และขอบเขต AI ด้วย mock เท่านั้น ไม่เสียค่า API ชุดสองตรวจว่าฟังก์ชันเดิมของ Repository ยังผ่าน

การทดสอบ Chromium เพิ่มเติมต้องมี Playwright (ฟรี; ไม่จำเป็นต่อการใช้งานแอป):

```powershell
npm install --prefix .qa-tools --no-save playwright@1.64.1
node .qa-tools/node_modules/playwright/cli.js install chromium
$env:PLAYWRIGHT_MODULE=(Resolve-Path .qa-tools/node_modules/playwright).Path
node ai-money-studio/tests/business-insights.browser.cjs
```

ไม่ Commit `.qa-tools/` หลักฐานภาพและรายงานสมมติจะอยู่ในโฟลเดอร์ชั่วคราว `woramet-browser-qa` ตั้ง `WORAMET_QA_DIR` เพื่อเปลี่ยนที่เก็บได้ ตั้ง `CHROMIUM_PATH` เมื่อต้องการใช้ Chromium ที่ติดตั้งแล้ว

## สิ่งที่ต้องทำต่อโดยเจ้าของอนุมัติ

- ยืนยันกติกาใช้โค้ดที่มีอยู่ก่อนแข่ง ชื่อ Track และเงื่อนไข Marketplace กับผู้จัด
- อนุมัติผู้ให้บริการ AI งบประมาณ ข้อมูลที่จะส่ง และการจัดเก็บ Key ใน server secret ก่อนเริ่มเชื่อมจริง
- เพิ่มระบบยืนยันตัวตน/สิทธิ์ร้าน/โควตาอย่างถาวรก่อนเปิด AI ให้คนอื่นใช้
- ตรวจ Safari บน iPhone จริงผ่านลิงก์ทดลองที่อนุมัติแล้ว; การ Deploy ถาวรและการส่งประกวดยังต้องขออนุมัติแยก

ไม่มีการแก้ `main`, Merge หรือเรียก AI แบบเสียเงิน ลิงก์ทดลองไม่ได้เปลี่ยนเว็บไซต์จริงหรือการตั้งค่า Deploy เดิม
