# QuoteFlow 1.0

The current quotation module imports supported CSV, DOCX tables, single-sheet XLSX and selectable-text PDF tables. It requires an independently entered expected item count and manual review before final output.

Open `ai-money-studio/quote-flow.html` over HTTP/HTTPS. The example contains 30 synthetic items, 60 units and a total of THB 750.00. Documents stay in the browser. No runtime AI, photo/scanned OCR, tax calculation, payment processing or LINE sending is connected.

Current scope, restrictions, test evidence, pre-event disclosure, submission copy and commercial draft are in [docs/quoteflow-2026](../docs/quoteflow-2026/README.md). The product has not been submitted or listed for sale.
