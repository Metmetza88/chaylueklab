# กรณีทดสอบโรงเรียนบ้านระหาร — ยังไม่ได้ดำเนินการ

ยังไม่มีไฟล์โลโก้ต้นฉบับที่ใช้งานได้ในงานนี้ ไฟล์ใน `samples/` เป็นตราสังเคราะห์เท่านั้น ห้ามใช้ผลของตราสังเคราะห์แทนผลตรวจโลโก้โรงเรียน

เมื่อได้รับไฟล์ PNG/JPG ต้นฉบับที่มีสิทธิ์ใช้งาน:

1. เก็บสำเนาต้นฉบับและ SHA-256 ระบุขนาดพิกเซล ตรวจว่าตัวหนังสือไทยอ่านชัดและขอบไม่แตก
2. ตัดขอบว่างหรือบันทึกความกว้างขอบว่าง เพราะขนาด 50 มม. ในระบบรวมทั้งภาพ ไม่ใช่ขอบเขตหมึกเสมอไป ตั้งกว้าง 50 มม. รักษาสัดส่วน เลือกผ้าที่จะใช้จริง เครื่อง Tajima หัวเดียว
3. เลือกจำนวนสีตามโลโก้จริง (1–15) เทียบภาพต้นฉบับกับผลแยกสี ตรวจอักษร สระ วรรณยุกต์ ช่องไฟ และขอบวงกลม ห้ามถือว่าการแยกสีคือการตรวจตัวอักษรผ่าน
4. ทดสอบ Running และ Tatami รุ่นทดลองหลายค่า density/angle/length บันทึก settings และ warnings ทุกครั้ง Thai lettering ขนาดเล็กอาจต้องวาด Satin/Running ใหม่ด้วยคน Auto Satin/Text ไม่พร้อมใช้งาน
5. ตรวจลำดับสี Underlay, Jump, เส้นสั้น, จุดเริ่ม/จบ และแนว fill ผ่านรูเจาะใน simulation เทียบกับไฟล์ DST ที่อ่านกลับ ตรวจจำนวนฝีเข็ม/สี/ขนาดจริงทั้งแกนและ max/min length
6. เปิดไฟล์ในโปรแกรมตรวจลายปักภายนอก ตรวจ hoop, จุดเริ่ม, ความเข้ากันได้กับรุ่นเครื่อง และกำหนดสีจริงตาม `.threads.json` DST รุ่นนี้ไม่สั่ง Trim โดยตรง แต่ Jump ต่อเนื่องอาจถูกตีความเป็นการตัดด้าย ต้องตรวจการตั้งค่าเครื่อง
7. **ผู้ควบคุมเครื่องที่มีประสบการณ์** เลือกผ้า ด้าย เข็ม วัสดุรอง ความตึง ความเร็ว แล้วทดลองบนผ้าสำรองก่อน ห้ามปักงานลูกค้าทันที
8. บันทึกรุ่นเครื่อง/สะดึง/ผ้า/เข็ม/รองปัก/ด้าย/ความเร็ว ตลอดจนภาพผลปัก ปัญหาด้ายขาด/รั้ง/ย่น ความหนาแน่น ขอบและอักษรไทย พร้อมผู้ตรวจและวันที่
9. ปรับแก้และทดลองซ้ำ เก็บไฟล์ต้นฉบับ/แบบ/ไฟล์เครื่อง/ลำดับสี/ผลอ่านกลับ/รูปตัวอย่างที่มีเลขเวอร์ชันตรงกัน ผลซอฟต์แวร์ผ่านอย่างเดียวไม่ใช่การยืนยันใช้งานกับ Tajima จริง

สถานะทุกหัวข้อ: **รอไฟล์ต้นฉบับและผลทดสอบกับเครื่องจริง** ไม่มีผลการทดสอบปักในรายงานนี้
