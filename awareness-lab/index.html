นี่คือการทดสอบฟิชชิ่ง

คุณเพิ่งพบหน้าเข้าสู่ระบบที่มีหน้าตาคล้ายระบบองค์กรจริง ผู้โจมตีอาจใช้หน้าแบบนี้หลอกให้กรอกรหัสผ่านหรือ OTP ได้

  • ตรวจสอบโดเมน URL ก่อนกรอกข้อมูลทุกครั้ง
  • อย่าเข้าสู่ระบบผ่านลิงก์ที่ไม่คุ้นเคยในอีเมล
  • ใช้ Passkey หรือ FIDO2 Security Key เมื่อรองรับ
  • รายงานข้อความสงสัยให้ผู้ดูแลระบบ

หน้านี้ไม่เคยเก็บหรือส่งข้อมูลที่คุณพิมพ์ และไม่มีการเข้าสู่ระบบจริง
