# CHAYLUEKLAB Affiliate AI Studio — Windows v1.0

Local-first โปรแกรมจัดการสินค้า Shopee Affiliate, ทำร่างโพสต์ และทำคลิป MP4 แนวตั้ง ข้อมูลสินค้าของคุณเก็บเป็น SQLite **บนเครื่องตัวเอง** ไม่ต้องมีบัญชี ChatGPT, Supabase, Vercel หรือ API key สำหรับฟีเจอร์พื้นฐาน

## เริ่มใช้บน Windows

**วิธีง่ายที่สุด (หากมี EXE จาก GitHub Actions):** ดาวน์โหลด artifact ของ workflow `Build Shopee Affiliate Windows EXE` จาก GitHub, แตกไฟล์ แล้วดับเบิลคลิก `CHAYLUEKLAB_Affiliate_AI_Studio.exe` โปรแกรมเปิดเว็บหน้าต่างในเบราว์เซอร์เริ่มต้นที่ `127.0.0.1` ให้อัตโนมัติ **EXE ใช้ได้บน Windows 64-bit เท่านั้น**

**วิธีใช้ไฟล์ ZIP นี้:**

1. ติดตั้ง Python 3.11–3.13 จาก https://www.python.org/downloads/windows/ และติ๊ก `Add Python to PATH` ตอนติดตั้ง
2. แตก ZIP แล้วดับเบิลคลิก `start_windows.bat` หน้าต่างเบราว์เซอร์จะเปิดเอง
3. หากจะสร้างวิดีโอ ให้ดับเบิลคลิก `install_video_windows.bat` **หนึ่งครั้ง** (ต้องมีอินเทอร์เน็ตเฉพาะตอนติดตั้ง Pillow และ FFmpeg ที่มากับ imageio-ffmpeg)
4. เปิดหน้า **คลังสินค้า** เพื่อเพิ่มสินค้า/กรอกราคา/ค่าคอม/ลิงก์ Affiliate จริง; จากนั้นไปหน้า **AI เขียนคอนเทนต์** หรือ **บอตและคลิปวิดีโอ**
5. ปิดหน้าต่าง Command Prompt ที่เปิดโปรแกรม เพื่อหยุดเซิร์ฟเวอร์ภายในเครื่อง การปิดแท็บเว็บอย่างเดียวไม่ปิดโปรแกรม

ข้อมูลอยู่ที่ `%LOCALAPPDATA%\CHAYLUEKLAB\AffiliateAIStudio\` แยกจากเว็บไซต์ CHAYLUEKLAB เดิมและ LINE OA เดิม มีไฟล์ `studio.db`, ภาพสินค้าใน `images/` และคลิป/โพสต์ใน `outputs/` สำรองข้อมูลได้ด้วยการคัดลอกโฟลเดอร์เมื่อปิดโปรแกรมแล้ว

### สิ่งที่ทำได้จริง

- เพิ่ม แก้ไข ลบ ค้นหา และส่งออกสินค้า CSV; นำเข้ารายการสินค้าจาก CSV
- บันทึกชื่อ ราคา อัตราคอมมิชชัน (กรอกเอง), ลิงก์ Affiliate, ภาพสินค้าที่มีสิทธิ์ใช้
- คำนวณค่าคอมมิชชัน **ประมาณการต่อออเดอร์** (`ราคา × อัตรา/100`) และจัดอันดับตามข้อมูลที่กรอก
- เขียนแคปชั่น/สคริปต์ 12 วินาทีด้วยเทมเพลตออฟไลน์ หรือใช้ Ollama ที่ `127.0.0.1:11434` (ต้องติดตั้งโมเดลเอง)
- บอตสร้างชุดโพสต์ TXT ได้สูงสุด 30 รายการต่อครั้ง ไม่โพสต์อัตโนมัติ
- สร้าง MP4 แนวตั้ง 720 × 1280 (9, 12 หรือ 15 วินาที) จากภาพสินค้าและข้อความ เป็น **สไลด์ 3 ฉากแบบไม่มีเสียง**
- นำเข้า CSV รายได้จากแดชบอร์ดที่มีหัวคอลัมน์เข้ากันได้ (`commission` / `ค่าคอมมิชชั่น`) โดยลบแถวซ้ำจากเนื้อหาแถวเดียวกัน
- เริ่มต้นด้วย 2 ลิงก์ Shopee ที่พบใน affiliate center ของ GitHub เดิม แต่ **ไม่ได้ยืนยัน** ชื่อจริง ราคา สินค้า หรือค่าคอม

### สิ่งที่ *ยังไม่ทำ* ใน v1.0

- ไม่ได้ดึงสินค้าจาก Shopee แบบเรียลไทม์ ไม่ได้ตรวจยอดขายจริง ไม่ได้โพสต์ Shopee Video อัตโนมัติ และไม่ได้เปิด Shopee Affiliate API ที่ต้องได้รับอนุญาตจาก Shopee
- ยังไม่รองรับตัดต่อวิดีโอจากคลิปถ่ายจริง, เพิ่มเพลง/เสียงบรรยาย, พากย์เสียง และอนิเมชัน
- ไม่ใช่การรับประกันรายได้ ตัวเลขคาดการณ์จะขึ้นกับข้อมูลที่ผู้ใช้กรอก และต้องตรวจราคา/ค่าคอมใน Shopee ก่อนโพสต์
- รายงาน CSV ของ Shopee มีหลายรูปแบบ หากหัวคอลัมน์ไม่ตรงกัน ให้เปลี่ยนชื่อคอลัมน์ก่อนนำเข้า

### ความปลอดภัย

- ใช้เฉพาะ `http://127.0.0.1` (ไม่มีการเปิดให้คอมเครื่องอื่นเข้ามา)
- POST API มี session token เฉพาะรอบการเปิดแอป และตรวจ Origin
- ไม่มีการเก็บรหัสผ่าน Shopee หรือโทเค็น LINE OA
- การเรียก Ollama เกิดที่ `127.0.0.1:11434` เท่านั้น ข้อความสินค้าถูกส่งไปที่บริการ Ollama ภายในเครื่อง (ขึ้นกับการตั้งค่าของ Ollama)
- ต้องใช้ภาพที่คุณเป็นเจ้าของหรือได้รับอนุญาต และตรวจข้อความจริงก่อนเผยแพร่
- หากใช้ EXE ที่แจกจ่ายต่อควรตรวจที่มาของ artifact และสแกนไวรัสด้วย Windows Defender

## สำหรับนักพัฒนา

```sh
python -m unittest discover -s tests -v
python app.py --no-browser --port 8888
python -m pip install -r requirements-video.txt
```

Workflow `.github/workflows/affiliate-ai-windows.yml` ของ repo เดิม build Windows EXE โดย PyInstaller เมื่อ push สาขาที่มีโปรแกรมนี้หรือสั่งผ่าน workflow_dispatch (หลังนำเข้า workflow บน branch ที่ GitHub ยอมให้รัน)

**หมายเหตุ:** นี่เป็นต้นฉบับสำหรับเครื่อง Windows ไม่ได้ใช้ในระบบรับชำระเงิน หรือเว็บไซต์/LINE OA ของ CHAYLUEKLAB
