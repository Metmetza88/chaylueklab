# WORAMET SPECTRAL SCANNER v2.0
Native iOS SwiftUI prototype, isolated from the website.
- STAR: GPS, heading, raw magnetometer reading; star catalog not yet implemented.
- OBJECT: live camera preview; object classification not yet implemented.
- ANOMALY: microphone level in dBFS and raw magnetometer readings; no paranormal detection claims.
Requires Xcode on macOS to build locally. GitHub Actions can compile for simulator, but does not produce a signed installable IPA. For iPhone installation, Apple signing and provisioning are required.
