วิธีใช้งานจริง

1

Deploy เว็บเป็น HTTPS

นำไฟล์นี้ขึ้นโฮสต์ แล้วใช้ URL นั้นเป็น Endpoint URL ใน LINE Developers

2

ใส่ LIFF ID

LIFF ID ต้องมาจาก LINE Login channel ที่คุณกำลังสร้างอยู่

3

เปิดผ่าน LINE

ระบบจะดึงชื่อ รูปโปรไฟล์ UID และบริบท LINE จริงหลังผู้ใช้อนุญาตสิทธิ์

ทดสอบส่งข้อความกลับเข้าแชตได้เมื่อ LIFF มี scope chat_message.write และเปิดอยู่ใน LINE client
