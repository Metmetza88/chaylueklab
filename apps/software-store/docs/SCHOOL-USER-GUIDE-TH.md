# คู่มือ MET School Pro และ MET Admission

เวอร์ชัน 0.2.0-rc.2 — ใช้สำหรับตรวจรับก่อนใช้งานจริง

## เจ้าของโรงเรียน

เปิด `/school-admin/<slug>` ด้วยบัญชีที่กำหนดเป็น owner ตั้งชื่อ คำแนะนำ ช่องทางติดต่อ สี โลโก้ PNG/JPEG และปีการศึกษา เปิดเผยแพร่เว็บไซต์เมื่อเนื้อหาและนโยบายข้อมูลของโรงเรียนพร้อมแล้ว

ข่าวสารรองรับข้อความธรรมดาที่ระบบ escape เพื่อป้องกัน XSS เพิ่มข่าว แก้ไข และยกเลิกเผยแพร่ได้ ไม่รับ HTML ที่รันสคริปต์

สร้างรอบรับสมัคร ระบุชั้นโดยคั่นจุลภาค เช่น `ม.1, ม.4` ตั้งวันเปิดและปิด **เวลาไทย UTC+7** เปิด/ปิดรับสมัครแยกจากประกาศผล ระบบตรวจวันเวลา ระดับชั้น และสถานะรอบบนฐานข้อมูลทุกครั้ง

เพิ่มเจ้าหน้าที่ด้วย UUID ของบัญชีที่สมัครและยืนยันแล้ว บทบาท officer ตรวจใบสมัคร/เอกสาร, editor จัดการข่าวโดยไม่อ่านใบสมัคร, executive อ่านใบสมัคร/รายงาน, owner จัดการทุกส่วนในโรงเรียนของตน ถอนสิทธิ์ได้ทันทีจากฐานข้อมูล ไม่ใช้ user_metadata ที่ผู้ใช้แก้เองเป็นสิทธิ์

## ผู้ปกครอง

1. เปิด `/schools/<slug>` ดูประกาศและรอบที่เปิดอยู่
2. สมัครสมาชิก ยืนยันอีเมล แล้วเลือกสมัครเรียน
3. เลือกรอบและชั้น กรอกนักเรียน ผู้ปกครอง โทรศัพท์ โรงเรียนเดิม และยืนยันการแจ้งข้อมูล
4. เปิดหน้าตรวจสอบสถานะ เลขใบสมัครออกจากฐานข้อมูลอัตโนมัติ กด PDF เพื่อเก็บใบสมัคร
5. แนบรูปเอกสาร PNG/JPEG ไม่เกิน 5 MB ต่อภาพ แยกหลักฐานตัวตน ผลการเรียน และรูปถ่าย รูปถูกถอด metadata และแปลงใหม่ก่อนเก็บใน private bucket ห้ามใช้ Demo ส่งเอกสารจริง
6. เมื่อเจ้าหน้าที่ขอเอกสารเพิ่ม เปลี่ยนไฟล์ชนิดนั้นได้ สถานะอนุมัติ/ปฏิเสธมาจากเจ้าหน้าที่และประกาศผลตามรอบของโรงเรียน

## เจ้าหน้าที่และผู้บริหาร

เปิดหน้า admin ของโรงเรียน ดูสรุปจากจำนวนใบสมัครจริง และตรวจใบสมัครล่าสุด 100 รายการ ไฟล์เอกสารเปิดผ่าน Signed URL 60 วินาทีเฉพาะผู้มีสิทธิ์ ตรวจข้อมูลแล้วเลือกขอเพิ่ม/อนุมัติ/ปฏิเสธพร้อมหมายเหตุที่ผู้ปกครองอ่านได้

CSV สำหรับ Excel มี UTF-8 BOM และป้องกันสูตรจากข้อมูลข้อความ ส่งออกสูงสุด 10,000 รายการต่อครั้ง มี Audit Log ไม่มีรายชื่อเด็กสาธารณะ เปิดประกาศผลให้ผู้ปกครองตรวจบัญชีตนเอง

## ความเป็นส่วนตัวและการสำรอง

โรงเรียนต้องยืนยันฐานการประมวลผล ประกาศข้อมูล ระยะเวลาเก็บ และผู้รับผิดชอบการลบ/สำรอง ก่อนเปิดข้อมูลจริง ไม่ถือว่าการมี checkbox เพียงอย่างเดียวทำให้ผ่าน PDPA ทุกกรณี ดู `SECURITY.md` และคู่มือติดตั้ง

Source ของ School Pro และ Admission ใช้ฐานร่วมกัน Admission รวมเว็บไซต์ประชาสัมพันธ์เพื่อให้ Workflow ต่อเนื่อง รุ่นนี้ยังไม่ครอบคลุมระบบทะเบียน เช็กชื่อ คะแนน หรือ 13 สินค้าที่ระบุเป็น Coming Soon
