# คู่มือเจ้าของร้านผ่าน iPhone

1. เปิด Safari ที่ URL ร้านค้าที่ตรวจรับแล้ว กดเข้าสู่ระบบด้วยบัญชีเจ้าของที่กำหนด UUID ไว้ ห้ามแบ่งรหัสผ่านกับเจ้าหน้าที่
2. เปิด `/admin` หรือเมนู Admin ที่ปรากฏสำหรับเจ้าของ หน้าแสดงยอดวันนี้ เดือนนี้ และสะสมจากคำสั่งซื้อเงินจริงที่ชำระแล้วเท่านั้น ไม่รวม Sandbox หรือคืนเงิน หากข้อมูลโหลดไม่ได้จะแสดงขีด/ข้อความ error แทนการสมมติยอด
3. เลื่อนส่วนคำสั่งซื้อ กดดูหลักฐาน แล้วเปิดแอปธนาคารตรวจเงินจริง ยอด ผู้รับ และเลขอ้างอิง ห้ามอนุมัติจากภาพเพียงอย่างเดียว กรอกยอดเป็น **สตางค์** (3,500 บาท = 350000) และเลขอ้างอิง เมื่อยืนยัน ระบบเปิด grant และเข้าคิวแจ้งเตือน
4. ถ้าข้อมูลไม่ตรง ใช้ปฏิเสธหลักฐานและบอกเหตุผล ลูกค้าเห็นเหตุผลในคำสั่งซื้อ
5. แก้ชื่อ ราคา หมวด รายละเอียด และซ่อนสินค้าได้จากส่วนสินค้า สินค้าใหม่เป็น Coming Soon จนมี release และหลักฐานทดสอบ
6. ดาวน์โหลด ZIP ที่จะอัปโหลดเข้า Files ก่อน ช่อง ZIP ในแอปนี้รองรับไม่เกิน 7 MB ระบุเวอร์ชันและ changelog อัปโหลดสำเร็จยังไม่เปิดขาย ต้องตรวจผลทดสอบและ SHA-256 ของ ZIP นั้นก่อน
7. ดูสมาชิก ปรับวัน VIP พร้อมเหตุผล และถอน grant ได้จากส่วนสิทธิ์ดาวน์โหลด การคืนเงินในหน้านี้เป็นการ **บันทึกหลังคืนเงินจริงภายนอกแล้ว** ไม่โอนเงินแทนธนาคาร
8. ส่วนช่วยเหลือใช้ตอบลูกค้าและเปลี่ยนสถานะ Audit Log และคิวระบบอัตโนมัติแสดงผลที่บันทึกจริง หากยังไม่ตั้ง endpoint จะไม่มีข้อความ LINE ส่งออก
9. กดออกจากระบบเมื่อใช้เครื่องร่วมกับผู้อื่น ห้ามเก็บ service role key หรือรหัสผ่านในโน้ตที่แชร์

URL Production ยังต้องตรวจรับก่อนใช้จริง คู่มือนี้ไม่ยืนยันว่า DNS หรือระบบแจ้งเตือนเปิดใช้งานแล้ว
