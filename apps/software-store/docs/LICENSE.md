# สิทธิ์การใช้งานซอฟต์แวร์ WORAMET AI LAB

Source Code ที่ WORAMET AI LAB พัฒนาขึ้นให้สิทธิ์ใช้งานภายในหนึ่งโรงเรียนหรือหนึ่งองค์กรต่อหนึ่งสิทธิ์ ปรับแต่งเพื่อใช้ภายในได้ ห้ามจำหน่ายต่อ แจกจ่าย Source Code, ZIP หรือบริการที่มีวัตถุประสงค์หลักเพื่อให้บุคคลภายนอกได้ซอร์สโดยไม่ได้รับอนุญาต

Release candidate นี้จัดส่งเพื่อประเมินและทดสอบ ยังไม่เป็นคำยืนยันว่าสินค้าพร้อมขายหรือเหมาะกับการประมวลผลข้อมูลเด็กจริง การซื้อขาย สิทธิ์สนับสนุน และการคืนเงินใช้ตามเงื่อนไขที่เจ้าของประกาศเมื่อเปิดขาย และไม่จำกัดสิทธิ์ตามกฎหมาย

Dependency ภายนอกใช้ตามสัญญาอนุญาตของแต่ละโครงการ โดยต้องเก็บ notices ของ dependency เมื่อเผยแพร่ ฟอนต์ Noto Sans Thai และ Noto Sans ใช้ SIL Open Font License 1.1 แนบไฟล์ OFL ใน public/fonts แล้ว
