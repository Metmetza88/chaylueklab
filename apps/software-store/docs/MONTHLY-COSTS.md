# ค่าใช้จ่ายรายเดือน — ประเมิน ณ 2026-11-24

นี่เป็นงบประมาณอ้างอิง ไม่ใช่ใบแจ้งหนี้บัญชีของเจ้าของ ไม่มีการสมัครแพ็กเกจเสียเงินหรือซื้อโดเมนในงานนี้

| รายการ | งบเริ่มต้นอ้างอิง | หมายเหตุ |
|---|---:|---|
| Vercel Pro | USD 20/เดือน | ตรวจเงื่อนไข commercial use และทีม/seat/usage จริงก่อนเปิดร้าน |
| Supabase Pro | เริ่ม USD 25/เดือน | หน้า pricing ระบุ project แรกและค่าเพิ่มสำหรับ project เพิ่มเติม ต้องตรวจองค์กรเดิม |
| รวมฐานตัวอย่าง 1 store project | ประมาณ USD 45/เดือน | ไม่รวมภาษี usage เกินโควตา seat เพิ่ม หรือ staging/compute เพิ่ม |
| SMTP สำหรับยืนยันอีเมล | ยังประเมินไม่ได้ | ยังไม่มีผู้ให้บริการที่เจ้าของเลือก/อนุญาต |
| API ตรวจสลิป/ธนาคาร | ยังประเมินไม่ได้ | ต้องมีบัญชีผู้ให้บริการและใบเสนอราคาจริง ไม่ใช้ราคาเดา |
| LINE OA / bridge / scheduler | ตามแผนและปริมาณ | ยังไม่เชื่อมส่งข้อความจริง ไม่มีการอ้างค่าใช้จ่ายศูนย์ |
| Domain renewal | ตามใบแจ้งหนี้ registrar | ใช้ subdomain ของโดเมนเดิม ไม่ได้ซื้อโดเมนใหม่ |
| Hosting โรงเรียนของลูกค้า | แยกจากร้านค้า | ขึ้นกับแต่ละ deployment และ Supabase Project |

อ้างอิงที่ตรวจอ่าน: [Vercel pricing](https://vercel.com/pricing), [Vercel Hobby](https://vercel.com/docs/plans/hobby), [Supabase pricing](https://supabase.com/pricing). ไม่แปลงเป็นเงินบาทเพราะไม่มีอัตราแลกเปลี่ยน/ค่าธรรมเนียมที่ยืนยันสำหรับใบเรียกเก็บจริง

ตั้ง spend alerts และเพดาน usage ในบัญชีของเจ้าของก่อนเปิดรับเงินจริง

ตรวจ Vercel context วันที่2026-11-27: พบ Project ร้านค้า chaylueklab-software-store ใน Teamเดิม plan Hobby และสร้าง Preview ได้แล้ว ไม่ได้อัปเกรดหรือซื้อแผน งบ Pro ด้านบนเป็นตัวอย่างสำหรับ commercial launch ที่ต้องให้เจ้าของเลือกและอนุมัติ ค่า API ตรวจสลิปเป็นทางเลือกหากเริ่มด้วยเจ้าของตรวจธนาคารด้วยตนเอง
