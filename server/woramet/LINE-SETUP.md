# WORAMET AI LAB — LINE OA integration (PREPARED, NOT CONNECTED)

เอกสารนี้เป็นงานเตรียมการสำหรับ **LINE OA ใหม่ของ WORAMET AI LAB เท่านั้น** ไม่ใช่ LINE OA ร้าน พ.สมนึก 2&3 และไม่ใช่ LINE ของ CHAYLUEKLAB ตัวเดิม ใช้ Repository `Metmetza88/chaylueklab` และสาขา `feature/woramet-dojo-mvp-20261113` ไม่แก้ `main` และไม่ Deploy

## ส่วนที่ทำแล้ว

- `line-webhook.mjs`: รับ LINE Messaging API webhook ที่ `/webhooks/line`, ตรวจลายเซ็น HMAC-SHA256 ของ **raw body** ก่อนอ่าน event, จำกัดขนาดคำขอ 64 KB และ 20 events, รับเฉพาะข้อความคุยตัวต่อตัว (ไม่รับกลุ่ม), ตอบผ่าน LINE reply API
- `line-preview.mjs`: เซิร์ฟเวอร์ทดลอง Node.js **เฉพาะ 127.0.0.1** ไม่เปิดให้ LINE ภายนอกเรียก ไม่ได้เชื่อมบัญชีจริง
- `ai-money-studio/tests/line-webhook.test.mjs`: ทดสอบด้วย Channel Secret และ Token ปลอม, mock LINE API; ไม่มีค่า API
- คำสั่งทดลอง: `เมนู`, `เริ่มใช้งาน`, `สรุปยอดขายตัวอย่าง`, `ทดลอง`/`demo`; รายงานใช้ engine คำนวณยอดขายใน `business-insights-core.js` และ **ข้อมูลสมมติ** เท่านั้น
- คำสั่ง `ยอดขายวันนี้`, `ใบเสนอราคา`, `ส่งเอกสาร`, `สร้างรูป`, `ถาม AI` แจ้งอย่างชัดเจนว่ายังไม่พร้อมใช้งาน ไม่แต่งตัวเลข ไม่อ้างว่าสร้างรูปหรืออ่านไฟล์แล้ว

## หน้าแชตจำลองสำหรับสาธิต

- เปิด `ai-money-studio/line-demo.html` ผ่าน static server เพื่อทดลองหน้าจอแชต (ไม่ใช่ LINE จริง)
- คำสั่ง `เมนู` และ `สรุปยอดขายตัวอย่าง` ใช้ข้อมูลสมมติจาก Business Insights; `ใบเสนอราคา` เปิดตัวอย่างที่พิมพ์/บันทึกเป็น PDF ผ่านเมนูพิมพ์ของเบราว์เซอร์ได้
- `ส่งเอกสาร` / `สร้างรูป` เป็นเพียงข้อความแจ้งว่ายังไม่เปิดใช้ ไม่มีการอัปโหลดไฟล์หรือเรียก AI
- ยังไม่ผ่านการทดสอบ Safari บน iPhone จริงหรือ Chrome/Edge บน Windows จริง ต้องตรวจด้วยอุปกรณ์ก่อนใช้สาธิตต่อกรรมการ

## ทดลองใน Windows (ไม่ต้องใช้ LINE จริง)

ใช้ Node.js 22+ จากราก Repository:

```powershell
node --test ai-money-studio/tests/line-webhook.test.mjs
node server/woramet/line-preview.mjs
```

การเปิด `line-preview.mjs` โดยไม่มี Secret/Token จะตอบ HTTP 503 อย่างตั้งใจ ส่วนชุดทดสอบจะจำลองการเซ็นลายเซ็นและการส่งคำตอบโดยไม่ส่งข้อความออก LINE จริง

## ขั้นตอนเชื่อมบัญชีจริง — ยังไม่ได้ทำ

1. เจ้าของสร้าง LINE Official Account ใหม่ชื่อ `WORAMET AI LAB` และเปิดใช้งาน Messaging API ของบัญชีนั้น (แยกจาก OA ร้าน)
2. เก็บ **Channel Secret** และ **Channel Access Token** ของบัญชีใหม่ไว้ใน Secret Manager ของเซิร์ฟเวอร์ที่เจ้าของอนุมัติ ห้ามวางใน GitHub, เว็บ, LINE, ภาพหน้าจอ หรือส่งในแชต
3. เลือกโฮสต์ HTTPS ที่รับ POST `/webhooks/line` ได้จริง แล้วทำ production adapter สำหรับสภาพแวดล้อมนั้น พร้อม HTTPS, logging ที่ไม่เก็บข้อความ, การจำกัดการเรียก, ความพร้อมใช้งานและการจัดการ retry
4. ตั้ง Webhook URL ใน LINE Developers/LINE OA Manager ตามช่องทางที่ระบบแสดง เปิด `Use webhook` และทดสอบ verify กับบัญชีใหม่เท่านั้น
5. ทดสอบข้อความ `เมนู` และ `สรุปยอดขายตัวอย่าง` จากบัญชี LINE ของเจ้าของ; ตรวจไม่ชนกับระบบตอบกลับอัตโนมัติของ LINE
6. ก่อนเพิ่มอ่านเอกสาร/สร้าง PDF/สร้างภาพ/Generative AI: ต้องอนุมัติ provider, ค่าใช้จ่าย, การเก็บไฟล์, การลบข้อมูล, ความยินยอม, ระบบสิทธิ์และโควตา และทดสอบข้อมูลสมมติ

**สถานะ:** โค้ดต้นแบบพร้อมสำหรับการทดสอบออฟไลน์ แต่ **ยังไม่มี OA ใหม่, ไม่มี webhook สาธารณะ, ไม่ได้ส่งข้อความ LINE จริง, ไม่มี AI ที่เชื่อมอยู่, ไม่มีระบบรับเงิน**. ห้ามระบุว่าเชื่อม LINE สำเร็จหรือพร้อมขายจนกว่าจะทดสอบครบ

## ข้อจำกัดสำหรับ Dojo
